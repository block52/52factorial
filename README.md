# 52! (Fifty Two Factorial)

A software development company building the future of onchain poker.

## About

52 factorial (52!) is the number of possible ways to arrange a standard deck of 52 playing cards — approximately 8×10^67 unique combinations. This astronomical number represents the foundation of fair, unpredictable gameplay.

We leverage this mathematical certainty alongside blockchain technology to create provably fair, trustless poker experiences.

## Flagship Product

### [Block52](https://block52.xyz)

A fully decentralized poker platform featuring:

- **Mental Poker Protocol** - Cryptographic card shuffling without a trusted dealer
- **Zero-Knowledge Proofs** - Verify card ownership without revealing hands
- **Non-Custodial Wallets** - Players maintain full control of their funds
- **Instant Settlements** - Smart contract-based payouts

## Technology

Our platform is built on cutting-edge cryptographic protocols:

- Mental Poker for trustless shuffling
- Smart Contracts for immutable game logic
- ZK Proofs for privacy-preserving mechanics
- Commit-Reveal schemes for fair betting
